# 对话分组整理 Skill v2.0

## 触发条件
手动触发，或由每月定时工作流调度执行。

## 步骤

### Step 1：列出所有对话
调用 `extended_chat:list_chats` 获取全部对话列表（limit设为250，确保全量）。

### Step 2：筛选未分组对话
找出标题中 **不包含** 以下前缀的对话：
- `[技术]` `[游戏]` `[学习]` `[小说]` `[心理]` `[家庭]` `[数码]` `[财经]` `[人文]` `[日常]`

### Step 3：对每条未分组对话进行分类

#### 分类规则（v2.0 — 10大类）

| 分组 | 含义 | 匹配关键词 |
|------|------|-----------|
| **`[技术]`** | 开发·逆向·工具链·AI开发 | 编程、开发、APK、逆向、反编译、GitHub、代码、bug、修复、魔改、串流技术、AI模型、API、工作流、skill、agent、部署、配置、token、哈希、检测、项目结构、测试、服务器、同步（技术实现） |
| **`[游戏]`** | 游戏游玩与讨论（含游戏开发项目） | 游戏名、外挂、玩游戏、通行证、模组、游戏推荐、游戏价格、3A、游戏开发、战锤、游戏历史 |
| **`[学习]`** | 高考备考·学科学习 | 高考、作文、阅读、句子、素材、检讨、作业、考试、英语、数学、物理、网课、语文、文言文、标点、谜题、笔记 |
| **`[小说]`** | 小说阅读 | 下载...小说、看书、书单、小说名 |
| **`[心理]`** | 情绪·心理·健康·药物 | 孤独、倾诉、情绪、抑郁、焦虑、药物、副作用、分手、情感陪伴、自我怀疑、压力、失眠、心理 |
| **`[家庭]`** | 家庭事务·财务·维权·亲人 | 家人、家庭财务、卖房、负债（家庭）、租客、维权、家长管理、家事 |
| **`[数码]`** | 硬件·选购·数码设置 | 手机、电脑、电视、显卡、CPU、游戏机、串流设置、开发者选项、硬件对比、处理器、耳机、平板 |
| **`[财经]`** | 经济·股市·消费决策 | 关税、股灾、股市、救市、比特币、负债（投资）、理财、价格分析、经济、融资、公司 |
| **`[人文]`** | 文学·哲学·科学·文化闲聊 | 诗、词、赏析、哲学、意识、量子、悖论、逻辑、风水、神话、历史、文化、美食、书法、社会现象、法律知识、影视剧情 |
| **`[日常]`** | 日常生活·兜底 | 出行、吃饭、电影活动、购物消费、闲聊、角色卡陪伴对话、无法归类的 |

#### 兜底规则
- 以上都不匹配 → `[日常]`（仅真正无法归类的内容）
- 边界判定：标题含开发/代码/项目 → [技术]；含游戏名/游玩 → [游戏]；含学科内容 → [学习]；含情绪/健康 → [心理]；含家人/家事 → [家庭]；含硬件参数/数码设备 → [数码]；含经济议题 → [财经]；其余知识性闲聊 → [人文]

### Step 4：处理重复对话
1. 按标题（忽略前缀后）分组，找出重复组
2. 每组保留 messageCount 最大的一条为主对话，其余为副对话
3. 合并方式：主对话保留，副对话删除（如需保留内容，先读取确认无独有信息）

### Step 5：执行重命名
对每条未分组对话调用 `extended_chat:rename_chat`，加上对应的前缀标签。
已有旧前缀（v1.0）的对话，按新规则改到新体系。

### Step 6：汇报结果
- 处理了多少条对话、各分组分别有多少条、合并了多少条重复对话、剩余未分组数量（应为0）

## 约束
- 不要删除任何对话（除非用户明确授权合并重复项）
- 如果对话标题包含敏感内容，保留原标题不变，仅加前缀
- 合并重复对话必须保留消息数最多的那条
